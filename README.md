## ⚙️ Instalación

```bash
# 1️⃣ Clona el repositorio
git clone https://github.com/jandomen/mi_portafolio_de_evidencias.git

# 2️⃣ Entra al directorio
cd mi_portafolio_de_evidencias

# 3️⃣ Instala las dependencias
npm install
```

## 🎮 Uso

```bash
# 🔥 Inicia el servidor de desarrollo
npm run dev

# 🏗️ Compila para producción
npm run build

# ▶️ Ejecuta la versión de producción
npm start
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador para verlo. 🎉

## 🚀 Despliegue

El proyecto está desplegado en **Vercel**. Para desplegarlo tú mismo:

1. Haz push del código a GitHub 📤
2. Importa el proyecto en [Vercel](https://vercel.com) 🔗
3. Vercel detectará Next.js automáticamente ✅
4. ¡Listo! Tu portafolio estará en línea 🌐
